# Pure Live 3.1.2 — 桌面弹幕小窗与斗鱼后台续期

版本 `3.1.2+4115`，Windows x64 与 macOS Universal。

- 播放界面的小窗按钮支持 Windows / Mac；保留视频、当前弹幕及双流解说。
- 小窗可置顶、拖动、缩放；鼠标移入显示播放、弹幕和返回按钮，双击或 Esc 返回，空格暂停/播放。
- 恢复进入前的大小、位置、置顶、最大化与全屏状态。Mac 等待系统全屏完成事件后再调整窗口，并支持在其他桌面显示小窗。
- 每次启动后静默尝试一次斗鱼 Cookie 续期，验证成功后保存最新会话，不强制重连正在播放的流。
- 续期使用应用网页登录留下的长期凭据。只有手动粘贴的短期 Cookie 时，请先在应用内重新登录一次；长期凭据也失效时仍需重新登录。
- 续期失败保留原 Cookie；账号页显示状态并可手动重试。退出登录、切换账号或编辑 Cookie 会隔离在途结果。

代码与自动化验证不等同于真实账号和每种系统窗口管理器已实测。交付状态、构建提交、校验和与验证记录见 [本轮记录](DESKTOP_PIP_DOUYU_REFRESH_2026_11_02.md)。
本轮桌面产物不表示 Android / iOS / Linux 已完成新版本交付；这些平台的更新记录保持原状态。
