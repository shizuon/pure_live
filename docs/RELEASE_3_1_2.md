# Pure Live 3.1.2 — 桌面小窗、斗鱼续期与虎牙取流修复

源码候选 `3.1.2+4115`，目标为 Windows x64 与 macOS Universal。

包含追加弹幕复制修改的最终业务源码已通过 665 项完整回归与静态分析（0 error / 0 warning），当前执行 Mac → Windows 串行云构建；安装包以正式上传的附件为准。

- 播放界面的小窗按钮支持 Windows / Mac；保留视频、当前弹幕及双流解说。
- 小窗可置顶、拖动、缩放；鼠标移入显示播放、弹幕和返回按钮，双击或 Esc 返回，空格暂停/播放。
- 恢复进入前的大小、位置、置顶、最大化与全屏状态。Mac 等待系统全屏完成事件后再调整窗口，并支持在其他桌面显示小窗。
- 每次启动后静默尝试一次斗鱼 Cookie 续期，验证成功后保存最新会话，不强制重连正在播放的流。
- 续期使用应用网页登录留下的长期凭据。只有手动粘贴的短期 Cookie 时，请先在应用内重新登录一次；长期凭据也失效时仍需重新登录。
- 续期失败保留原 Cookie；账号页显示状态并可手动重试。退出登录、切换账号或编辑 Cookie 会隔离在途结果。

- 画面、桌面小窗和侧栏弹幕支持单击复制正文，不含用户名；长按／右键仍可打开屏蔽菜单。
- 播放器顶部标题和渐变背景透传点击，前两行弹幕可正常选中；真实按钮仍可操作。
- 点击按下时锁定该条弹幕，避免双击判定或长按等待期间移动后错选。

- 虎牙原生 FLV 续期改用 HTTPS；带签名模板的页面后备地址重新签名，完整不透明令牌保持原样。
- 虎牙 HLS 使用自己的签名材料，不再混用只返回 FLV 凭据的接口。
