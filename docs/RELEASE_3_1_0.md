# Pure Live 3.1.0 — 登录与画质

版本 `3.1.0+4113`。包含此前双流解说、校准、画面覆盖、三档解码和新增平台功能。

- 账号页优先官方网页登录，平台页面提供什么扫码/短信/密码方式就使用什么方式，应用自动保存会话；手动Cookie收进高级选项。B站保留独立扫码。
- 修正YY回退后仍标原画、B站返回档位不在旧菜单时标错、抖音旧会话遮蔽新登录、Twitch认证头缺失。
- 快手保留HEVC独有高画质；HLS缺少分辨率不再按码率猜1080P，不同编码/音轨不混为同档线路。
- 退出账号只清本站网页会话，不再清空其他平台；关闭登录页和二维码页后停止检测，晚到响应不会恢复旧账号。账号会话不进入设置备份。

**使用**：账号 → 对应平台 → 登录；保存后重新进入直播间，再选择画质。
登录不保证平台开放原画或特定帧率；会话已保存不等于权益验证通过。

**平台边界**

- Mac：Universal，Intel和Apple Silicon。
- Windows：x64安装器及便携包；网页登录需要WebView2运行时。
- Linux：x64归档；现有插件不支持内嵌网页登录，B站可扫码，其他平台保留高级入口。
- iOS/iPadOS：arm64普通未签名IPA，需要自行签名。
- Android：arm64测试APK另见构建记录，含共用TV模式。仓库尚无正式签名密钥，
  临时测试证书可能无法覆盖旧版，不作为正式升级包发布。未提供独立32位或TV仓库构建。

实际下载只以本Release已上传资产为准，构建状态与SHA见
[完整交付记录](https://github.com/shizuon/pure_live/blob/master/docs/PLATFORM_LOGIN_3_1_0.md)。
真实设备扫码、验证码、账号原画权限、HDR和长期播放仍需测试，不能由编译通过代替。
