# Pure Live 3.0.24 — 斗鱼网页登录与实际画质

本次提供 macOS Universal DMG / ZIP（Apple Silicon 与 Intel），版本 `3.0.24+4112`。

- **不用复制 Cookie**：账号 → 斗鱼 → 登录斗鱼，打开官方网页登录页，使用页面提供的扫码、短信或密码方式。完成后应用保存会话；手动 Cookie 放在折叠的高级选项里。
- **修正原画标记**：斗鱼返回蓝光4M时，不再继续显示请求的“原画1080P60”。不同实际画质的线路不混用，A、B 与录制都保留实际档位信息。
- 登录会话仅保存在本机，不进入备份导出。支持退出恢复匿名，关闭登录页会停止检测。保留原有硬解、双流同步、校准和覆盖功能。

登录后请重新进入直播间，再选择原画。以6657为例，本次匿名探测实际取得
1080p30的4M源，这解释了“选60帧却不够流畅”的一个具体原因；没有因此修改
硬件解码器或HDR输出设置。

**验证边界**：定向单元与相邻回归通过，静态检查通过；真实扫码、验证码、
登录账号的原画权限及300秒以上连续播放仍待用户测试。登录不保证平台放行
原画。此次未提供新版Windows、Android或iOS包。

详细证据与构建记录：[斗鱼帧率排查](https://github.com/shizuon/pure_live/blob/master/docs/DOUYU_FPS_AND_COOKIE_2026_09_26.md)。
SHA-256 校验文件随安装包提供。
