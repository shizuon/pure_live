## Twitch 遗漏：upstream-existing

用户样本 `croissantstrike`，StarLadder 决赛 / Counter-Strike。
公共 GraphQL 实测频道存在、正在直播、语言 `FR`、游戏 slug `counter-strike`。
原分区请求固定 `broadcasterLanguages: [ZH, KO]`，在接口请求时就排除了该频道。
另一个独立遗漏来自将 SearchCategoryTags 的 100 个推荐标签当作完整目录；
无标签或未入选标签的游戏无法进入 UI。改用无标签过滤的目录游标分页。
房间分页调用未传 pageSize，远端返回 30 条而 UI 只取所需数量，剩余条目被丢弃。
补齐 pageSize；刷新清理后续游标，避免新旧分页交叉；缺头像、游戏字段不再清空整页。
频道链接精确解析，合法登录名补充详情查询，不完全依赖搜索索引。

AngelLive `8cd8245df981d4fc0cc54e628da26b1772f00a6a` 当前主库通过外部插件源
加载平台，未找到可直接复用的 Twitch/Kick/YouTube 实现。本轮独立适配公共接口，
不引入其播放器实现。所有应用构建使用 GitHub Actions，平台串行。

验证需区分确定性适配器测试、公共接口探测、云构建及用户设备播放；
接口成功不代表所有地区、受限内容或长期播放均正常。回滚以本轮功能提交为单位。

## 3.0.23 候选支持范围

| 平台 | 发现和收藏 | 播放 | 弹幕 |
| --- | --- | --- | --- |
| Kick | 直播推荐、完整分类、分类直播、频道搜索、频道链接导入 | 公开直播 HLS，多画质，可选作 A/B | 动态读取公开 Pusher 配置，订阅成功才显示已连接，15 秒重试 |
| YouTube | 直播搜索、主题入口、视频链接及 @handle/channel 链接导入 | 公开直播 HLS，多画质，可选作 A/B | 公开直播聊天，按服务端间隔轮询，15 秒重连 |
| Twitch | 无语言限制的分类直播、无标签过滤的分类目录、登录名和链接精确查找 | 保留原播放实现 | 分类卡片使用 login 订阅，保留原 IRC 实现 |

YouTube 的主题入口是带直播过滤的搜索，不冒充完整平台分区目录。搜索只列正在直播的
视频，不包含普通录播和预告。视频链接收藏对应这场直播；频道链接收藏保留频道身份，
下次播放时重新找该频道当前直播。YouTube 不把 videoDetails.viewCount 的累计播放量
当成实时在线人数。Kick 搜索未给人数时留空。

无新增 SDK、外部服务器、yt-dlp/FFmpeg 子进程或媒体库替换。复用当前播放及双流流程，
包括高清 B 画质、校准、覆盖、A/B 弹幕选择及延迟、录制互斥。公开接口无法播放的
登录限定、会员、地区限制直播会报不可用；不实现登录和限制绕过。未开放聊天的
YouTube 房间明确显示未开放，不伪装连接成功，也不持续空轮询。

旧配置迁移仅加入两个新平台，不重新开启用户隐藏的旧平台。平台名称不变；
图标取自各自官网公开的 apple-touch-icon/favicon，仅用于标识对应平台，商标归原权利人。

## 外部接口证据

2026-09-21 匿名探测：

- Twitch：`croissantstrike` / `FR` / `counter-strike`；ChannelShell 和 StreamMetadata
  返回用户和 live 状态，primaryTeam 非关键字段偶发 service error，不阻止读房间。
  无标签目录首屏返回 100 项、包含 Counter-Strike 并提供下一页游标。
- Kick：搜索、分类和直播目录可用；直播目录至少返回 5 条，因此适配器缓存超额条目。
  在线房间 HLS 返回 5 档，含音轨。`web.kick.com/api/v1/realtime/channels/.../chat/connection`
  返回公开 Pusher 连接参数。旧固定实时连接地址不作为配置来源。
- YouTube：网页读取当前视频和客户端上下文；ANDROID 播放请求返回 HLS，清单可访问、
  共 6 档且含音轨。WEB/IOS 不一定返回 HLS，因此不会把其 adaptiveFormats 中的
  视频单轨 URL 当完整直播流。开放聊天的房间续页实测返回 73 条 action。
- 真实响应仅保留在本机忽略目录用于 Dart 回放测试，不提交签名播放 URL、聊天续页
  标识或访问者上下文。测试用例使用独立构造的数据。

设备验证尚未完成；当前证据不代表已在手机或桌面完成实际连续播放。
